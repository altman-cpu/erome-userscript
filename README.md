# erome-userscript & Neural Sync

This repository contains two things:

1. **`erome.user.js`** — the original userscript that displays video duration on erome.com albums.
2. **`neural-sync/`** — a new local-first workspace for content creators, coders and programmers.

---

## Neural Sync

> **Ideas held in memory — not on a blockchain.**

A controlled, private creative environment where all ideas live as associatively linked memory nodes — stored locally, linked by meaning, owned by you. No crypto, no wallets, no network.

See [`neural-sync/README.md`](neural-sync/README.md) for details. Open `neural-sync/index.html` in any browser to use it.

### Quick start
```bash
cd neural-sync
python3 -m http.server 8080
# → http://localhost:8080
```
